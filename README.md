# The Drive AI skills

Skills for AI agents that work with a person's files in [The Drive AI](https://thedrive.ai).

```bash
npx skills add thedriveAI/skills
```

| Skill | What it covers |
|---|---|
| [the-drive-ai](skills/the-drive-ai/SKILL.md) | Connecting (an MCP client, the CLI, or a sign-up with a claim link), working with paths and changesets, saving files, asking the agent, and what to say about limits. |

This repository is a mirror. The source is https://thedrive.ai/skills/the-drive-ai/SKILL.md, generated from the
same module that produces [thedrive.ai/agents.md](https://thedrive.ai/agents.md) and the MCP page, and written here
by `npm run skill:sync` in the web repository. Edits belong there; a pull request here will be overwritten.
